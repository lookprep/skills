# Changelog

Every manifest in this repository carries the same version. Claude Code updates an installed
plugin only when that version changes.

## 1.0.0

First public release.

- The `lookprep` Agent Skill: explain named lip looks, compare looks and amounts on stored demo
  simulations, quote prices, prepare consultation questions, and hand the person to lookprep.com
  with their chosen looks already selected.
- Plugin manifests for Claude Code, Codex (Agent Plugins 1.0.0), Cursor and Gemini CLI, all
  connecting the hosted, read-only MCP server at `https://mcp.lookprep.com/mcp`.
